# Web Design Guidelines: Modern UI/UX Standards

This skill governs the aesthetic and user experience standards for the GramBandhan web application.

## Core Design Principles

1. **Rich Aesthetics & Premium Feel**:
   - Avoid plain browser defaults or generic flat primary colors.
   - Use curated color palettes: emerald greens (`#059669`, `#10b981`), deep forest accents (`#064e3b`, `#022c22`), gold highlights (`#f59e0b`, `#d97706`), and slate dark backgrounds (`#0f172a`, `#1e293b`).
   - Employ subtle glassmorphism (`backdrop-filter: blur(12px)`, translucent borders `rgba(255, 255, 255, 0.08)`).
2. **Modern Typography**:
   - Clean, geometric sans-serif fonts: `Inter`, `Plus Jakarta Sans`, or `Outfit`.
   - Clear typographic hierarchy: distinct sizes, font weights (400, 500, 600, 700), and line heights for headings and body.
3. **Dynamic Micro-Interactions**:
   - Interactive hover states: smooth transitions (`transition: all 0.25s cubic-bezier(0.4, 0, 0.2, 1)`), subtle scale (`scale(1.02)`), gentle glows on action cards.
   - Meaningful feedback: active tabs, loading spinners, state pills, and status badges.
4. **Accessibility & Contrast**:
   - Meet WCAG AA contrast standards for all body copy and interactive labels.
   - Clear focus outlines for keyboard navigation.
