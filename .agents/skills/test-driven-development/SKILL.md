# Test-Driven Development (TDD)

Alias for `superpowers:test-driven-development`. See [superpowers-test-driven-development](../superpowers-test-driven-development/SKILL.md).

## Procedure
1. Red: Write a failing test.
2. Green: Implement minimal code to pass.
3. Refactor: Polish without breaking tests.
